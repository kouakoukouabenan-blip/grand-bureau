# Le Grand Bureau

Bureau virtuel d'agents IA (PWA) : un directeur et son équipe d'agents, chacun avec sa personnalité et sa fonction, travaillent visuellement sur vos missions et vous remettent un livrable (document, présentation, tableau, e-mail, code…). Propulsé par l'API Google Gemini.

**En ligne :** https://kouakoukouabenan-blip.github.io/grand-bureau/

Ajoutez votre clé API Gemini dans Réglages (clé gratuite : https://aistudio.google.com/apikey). Sans clé, l'application fonctionne en mode démo.
